Tutorial: sincronizar com seu GitHub

A sincronização guarda sua coleção no seu repositório do GitHub, então ela fica igual em qualquer aparelho e com histórico de versões. Cada usuário usa a própria conta — seus dados nunca se misturam com os de outra pessoa.

  1. Crie uma conta no GitHub, se ainda não tiver, em github.com.
  2. Crie um repositório (botão New). Dê um nome, ex.: gibiteca. Pode ser público.
  3. Publique o site (opcional): suba o arquivo index.html nesse repositório e ative Settings → Pages na branch main. Se você já abre o site por um endereço pronto, pode pular esta etapa.
  4. Gere um token de acesso: vá em github.com/settings/tokens → Fine-grained tokens → Generate new token. Em Repository access escolha Only select repositories e marque o seu repositório. Em Permissions → Repository permissions → Contents, mude para Read and write. Gere e copie (o GitHub só mostra uma vez).
  5. Conecte no app: abra o botão Nuvem, preencha usuário e repositório, cole o token e clique Conectar.
  6. Pronto. A partir daí tudo é salvo automaticamente. Em outro aparelho, conecte a Nuvem uma vez e a coleção aparece.

Dica: em um domínio próprio, o app não consegue adivinhar o usuário/repositório pela URL — basta preenchê-los manualmente na tela da Nuvem.
