Sincronizar com o GitHub

Isso salva sua coleção de volta no seu repositório, então ela fica igual em qualquer aparelho. Você precisa de um token do GitHub (uma chave de acesso limitada).
Passo a passo: 1) Acesse github.com/settings/tokens → Fine-grained tokens → Generate new token. 2) Em Repository access, escolha Only select repositories e marque o seu repositório da gibiteca. 3) Em Permissions → Repository permissions, ache Contents e mude para Read and write. 4) Gere, copie o token e cole aqui.
Guarde o token: o GitHub só mostra uma vez. Se vazar, você pode revogar na mesma página.
